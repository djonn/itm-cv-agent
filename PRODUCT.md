# CV Agent - Product Context

## Overview

CV Agent is an interview-style assistant that helps users write project experiences for their CV/resume. The application guides users through a conversational process to extract, refine, and polish professional project descriptions.

## Target Users

- Job seekers updating their CV
- Consultants documenting project work
- IT professionals creating portfolio pieces
- Danish-speaking users (primary language: Danish)

## Core Value

Transform rough thoughts and bullet points into polished, professional project experience descriptions through guided conversation.

## Platform

Web application (Phoenix LiveView)

## Register

Product UI (dashboard/admin tool) - design serves the product functionality

## Key Features

1. **Conversation Management** - Create, view, edit, and delete conversations
2. **Interview Flow** - Guided conversation to extract project details
3. **Project Experience Output** - Generate polished CV-ready text

## Design Direction

- Clean, professional interface suitable for career-focused users
- Danish language throughout the UI
- Minimal distractions, focus on writing and conversation
- Accessible, readable typography for extended writing sessions
- Subtle animations for state changes and transitions

## Brand Personality

- Professional yet approachable
- Supportive coach/guide
- Efficient and focused
- Trustworthy for career-critical content

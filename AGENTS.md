Technologies: Elixir, Phoenix, LiveView, Ecto, Postgres, Tidewave, req_llm
Product: CV Agent is an interview-style assistant that helps users write project experiences for their CV/resume. The application guides users through a conversational process to extract, refine, and polish professional project descriptions.
Checking code and debugging: Never run the application instead interact with it using Tidewave. If the application is not running ask the user to start it with `iex -S mix phx.server`, never start it yourself and never try to kill the process. You may still compile `mix compile --all-warnings`.
Communication: Use Simplified Technical English (ASD-STE100). Using Simplified Technical English will improve the clarity of technical writing.
